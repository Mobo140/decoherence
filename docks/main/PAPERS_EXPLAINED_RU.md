## 0. Словарь (чтобы дальше читалось без спотыканий)

| Термин | Что это на самом деле |
|---|---|
| **Декогеренция** | Кубит теряет «квантовость» из-за взаимодействия со средой и превращается в обычный классический бит. Вычисление ломается. |
| **T₂** | Время декогеренции: момент, когда когерентность падает до `1/e` (≈37%) от начальной. Практически — «сколько кубиту осталось жить». |
| **Когерентность `C(t)`** | Мера «квантовости». Считаем как `ℓ₁`-норму недиагональных элементов матрицы плотности: `C(t) = Σ_{i≠j} |ρ_ij(t)|`. Падает со временем. |
| **γ (гамма)** | Скорость диссипации — насколько быстро среда «съедает» кубит. |
| **γ(t)** | То же, но **меняется во времени**. Это и есть вся сложность задачи. |
| **Уравнение Линдблада** | Стандартное уравнение эволюции открытой квантовой системы (той, что взаимодействует со средой). Им мы симулируем траектории. |
| **σ₋ (сигма-минус)** | Amplitude damping — кубит теряет энергию, «сваливается» в основное состояние. |
| **σ_z (сигма-зет)** | Dephasing — энергия сохраняется, но теряется фаза. Другой механизм разрушения. |
| **Окно наблюдения** | Короткий кусок начала траектории, который модель видит. Остальное скрыто — надо предсказать. |
| **f** | Доля траектории в окне: `f = t_obs / T₂`. `f = 0.05` — видно только 5% жизни кубита. |
| **OLS** | Обычная линейная регрессия (метод наименьших квадратов). |
| **R²** | Насколько хорошо предсказаны *числа*. 1.0 — идеально, 0 — не лучше среднего, **отрицательное — хуже, чем просто всегда отвечать средним**. |
| **MAE** | Средняя абсолютная ошибка в тех же единицах, что T₂. Устойчивее R² к выбросам. |
| **AUROC** | Насколько хорошо работает *сигнал тревоги* (бинарный: «развалится в ближайшее время — да/нет»). 0.5 — монетка, 1.0 — идеально. |
| **BiLSTM** | Нейросеть для последовательностей, читающая окно в обе стороны. |
| **Transformer** | Архитектура на self-attention (та же, что в языковых моделях). |
| **XXZ / TFIM** | Два способа связать два кубита между собой. TFIM (Ising с поперечным полем) интересен тем, что у него есть **квантовый фазовый переход**. |

## 1. Общая идея обеих работ

### Задача

Дана **короткая начальная часть** траектории кубита — измеренные средние значения
операторов Паули. **Не дана** скорость диссипации `γ(t)`. Нужно предсказать:

1. **сколько осталось до декогеренции** (регрессия, метрика R²/MAE);
2. **сигнал тревоги**: развалится ли в пределах горизонта Δt (классификация,
   метрика AUROC).

Зачем: если знать заранее, система коррекции ошибок успеет сбросить или
перекодировать кубит до того, как точность упадёт ниже критической.

### Почему это вообще нетривиально

Если `γ` **постоянна** и шум амплитудный (σ₋), всё решается аналитически:

```
C(t) = C₀ · exp(−γ·t/2)   →   log C линеен по t
d(log C)/dt = −γ/2        →   T₂ = 2/γ = −1/наклон
```

То есть: берём логарифм когерентности, проводим прямую, `T₂ = −1/наклон`.
**Машинное обучение здесь не нужно** — формула даёт R² = 0.9995.

Задача становится содержательной **только когда `γ(t)` неизвестна и меняется**.
А это ровно то, что происходит на реальном железе:

| Платформа | Источник нестационарной γ(t) |
|---|---|
| Сверхпроводящие кубиты | 1/f шум потока, двухуровневые флуктуаторы |
| Спиновые кубиты | Сверхтонкое взаимодействие с ядерным спиновым бассейном |
| Ионные ловушки | Дрейф мощности лазера, микродвижение |
| Фотонные системы | Дрейф скорости утечки резонатора |

### Ключевая идея архитектуры: residual (остаточная) модель

Вместо того чтобы учить сеть предсказывать T₂ с нуля, мы **встраиваем формулу
прямо в архитектуру**, а сеть учит только поправку:

```
T₂ = T_физика(окно)  +  δT_сеть(окно)
     ↑ OLS-оценка       ↑ выученная поправка
```

Это даёт два свойства:

1. **Аналитический предел.** Если `γ` постоянна, сеть учится выдавать `δT ≈ 0` и
   мы точно воспроизводим формулу. Модель не может стать хуже физики.
2. **Лёгкая задача обучения.** Предсказывать небольшую поправку проще, чем
   абсолютное значение.

> Это **сильнее**, чем классические PINN (physics-informed neural networks). Там
> физика входит как штраф в функцию потерь, и сеть при желании может научиться
> его игнорировать. Здесь физика — жёсткое архитектурное ограничение: выход
> структурно разложен, сеть может только *добавить* поправку.

### Чем это отличается от ближайшей чужой работы

Chen & Kuo (Phys. Rev. A **112**, 042227, 2025) решают **обратную** задачу:

| | Chen & Kuo | Наша работа |
|---|---|---|
| Цель | Восстановить `γ(t)` | Предсказать остаток T₂ |
| Тип задачи | Обратная, офлайн | Раннее предупреждение, онлайн |
| Вход | **Полная** траектория | Короткое **раннее** окно |
| Выход | Коэффициенты Бернштейна | T₂ + риск-скор |
| Физика внутри | Нет | OLS-prior встроен |
| Аналитический предел | Нет | Да |

## 2. Статья 1 — один кубит

**Файл:** `paper/paper_1/main.tex`

### Что изучаем: три сценария

| Метка | Оператор скачка | γ(t) |
|---|---|---|
| **A** | σ₋ (amplitude damping) | постоянная |
| **B** | σ₋ | зависит от времени |
| **C** | σ_z (dephasing) | зависит от времени |

`γ(t)` параметризуется полиномами Бернштейна 4-й степени (это гарантирует
`γ(t) ≥ 0`), шесть качественно разных форм: константа, монотонный рост/спад,
пик, ступенька вверх/вниз.

### Эксперимент E1 — ablation: что реально вносит вклад

Сравниваем четыре варианта на одних и тех же данных (R², в скобках MAE):

| Вариант | A | B | C |
|---|---|---|---|
| `physics_only` (только формула) | **0.999** (0.056) | 0.753 (0.646) | 0.965 (0.113) |
| `lstm_only` (сеть без физики) | −0.446 (2.74) | 0.009 (1.92) | −0.029 (0.808) |
| `physics_lstm` (**наш**) | 0.976 (0.176) | **0.945** (0.356) | 0.976 (0.151) |
| `transformer` | 0.799 (0.631) | 0.902 (0.595) | **0.981** (0.136) |

**Что отсюда следует:**

1. **На сценарии A формула почти идеальна** (R² = 0.999). ML не нужен —
   и это важное честное утверждение, а не слабость работы.
2. **`lstm_only` проваливается на всех трёх** (R² от −0.45 до 0.01). Чистая
   сеть без физики не работает вообще. Значит физический prior —
   **необходим**, а не «полезная добавка».
3. **На B выигрыш от остаточной архитектуры максимален**: 0.945 против 0.753
   у чистой формулы, то есть **+0.19**. Это ровно тот режим, ради которого
   всё затевалось (нестационарная γ).

### Эксперимент E2 — насколько коротким может быть окно

Обучаем отдельную модель для каждой доли окна `f`:

| f | R² | MAE | AUROC |
|---|---|---|---|
| 0.05 | 0.711 | 0.825 | **0.933** |
| 0.10 | 0.723 | 0.813 | **0.950** |
| 0.15 | 0.735 | 0.773 | **0.947** |
| 0.20 | 0.736 | 0.702 | 0.872 |
| 0.30 | 0.734 | 0.677 | **0.969** |
| 0.50 | 0.697 | 0.674 | **0.990** |

**Главный вывод — и он тонкий:**

- **R² почти не растёт** с длиной окна (0.70–0.74 везде). То есть узкое место —
  не количество информации в окне, а смешение режимов B и C в одной модели
  (на одном B та же модель даёт 0.945 при том же размере окна).
- **AUROC при этом уже 0.933 при f = 0.05.** Сигнал тревоги надёжен, когда
  прошло всего **5% жизни кубита**.

> Практический смысл: **раннее предупреждение — это задача классификации, а не
> регрессии.** Планировщику коррекции ошибок не нужно точное T₂ — ему нужна
> откалиброванная вероятность «пора сбрасывать». Её мы даём рано и надёжно,
> а точное число — нет. В статье это явно оговорено: заявлять R² ≥ 0.95 по этим
> данным нельзя.

### Эксперимент E3 — устойчивость к шуму измерений

Добавляем гауссов шум σ к наблюдаемым:

| σ | R² | MAE | AUROC |
|---|---|---|---|
| 0.000 | 0.959 | 0.220 | 0.976 |
| 0.010 | 0.956 | 0.224 | 0.976 |
| 0.020 | 0.949 | 0.251 | 0.971 |
| 0.050 | 0.901 | 0.374 | 0.942 |
| 0.100 | 0.727 | 0.597 | 0.865 |

При реалистичном уровне σ = 0.05 держим R² = 0.901 и AUROC = 0.942. При σ = 0.10
AUROC падает до 0.865 — это практический потолок текущей архитектуры.

**Почему устойчивость вообще есть:** OLS-наклон считается по всему окну из 20
точек, и независимый шум усредняется примерно как `√W`. Физический prior даёт
шумоподавление «бесплатно», по built-in.

### Эксперимент E4 — одна модель на все сценарии

Обучаем одну модель на смеси A+B+C, проверяем на каждом по отдельности:

| Сценарий | R² | MAE | AUROC |
|---|---|---|---|
| A | 0.490 | 1.164 | 0.979 |
| B | 0.867 | 0.397 | 0.981 |
| C | **0.936** | **0.162** | **0.990** |

Интересный эффект: **на A смешанная модель хуже** специализированной формулы
(0.490 против 0.999). Причина понятна: при постоянной γ правильная поправка —
ровно ноль, а обученная на смеси сеть всё равно добавляет ненулевую δT.

Вывод для внедрения: лёгкий классификатор режима может выбирать между
`physics_only` (если `log C` в окне линеен) и `physics_lstm` (если нет).

### Эксперимент E5 — прямое предсказание против обратной задачи

Самое убедительное сравнение. Берём подход Chen & Kuo и применяем к **тому же**
короткому окну: (1) восстановить коэффициенты `γ(t)`, (2) численно проинтегрировать
и получить T₂.

| f | Прямой (наш) R² | Обратный R² | Прямой MAE | Обратный MAE |
|---|---|---|---|---|
| 0.10 | **0.922** | −0.856 | **0.259** | 1.390 |
| 0.15 | **0.825** | −1.468 | **0.378** | 1.573 |
| 0.20 | **0.827** | −0.827 | **0.394** | 1.358 |
| 0.30 | **0.909** | −1.256 | **0.304** | 1.543 |
| 0.50 | **0.956** | −3.039 | **0.160** | 1.493 |

Обратный подход даёт **R² < 0 при любой длине окна** — то есть работает хуже,
чем «всегда отвечать средним значением».

**Это не потому, что их сеть плохая.** Это фундаментальная некорректность
постановки: по короткому окну **много разных `γ(t)` одинаково хорошо
объясняют наблюдения**, и T₂, посчитанный из восстановленной γ, получается
с огромной дисперсией. Прямое предсказание обходит эту неопределённость
стороной — оно не пытается восстановить то, что не определено данными.

### Итог статьи 1

1. Чётко очерчено, **когда ML нужен, а когда нет**: при постоянной γ формула
   даёт 0.9995 и ML не нужен; он нужен только при нестационарной γ(t).
2. Остаточная архитектура даёт R² = 0.94–0.98 в нестационарных режимах
   и гарантированно вырождается в точную формулу в аналитическом пределе.
3. Сигнал тревоги AUROC ≥ 0.93 уже с первых **5%** траектории.
4. Прямое предсказание принципиально превосходит двухшаговое восстановление γ.

## 3. Статья 2 — два кубита

**Файл:** `paper/paper_2/paper2.tex`

### Что меняется при переходе к двум кубитам

Это не «то же самое, но больше». Три качественных отличия:

1. **Когерентность перестаёт быть экспонентой.** У связанных кубитов появляются
   когерентные осцилляции — `C(t)` может расти на отдельных участках окна.
   Предпосылка OLS («log C линеен») ломается.
2. **Богаче пространство признаков** — все 15 двухчастичных корреляторов Паули.
   Больше информации, но и больше шума.
3. **Запутанность создаёт отдельный канал распада**, зависящий от совместного
   состояния. У однокубитной формулы аналога этому нет. Более того,
   запутанность может исчезать **за конечное время** («entanglement sudden
   death», Yu & Eberly, Science 323, 598), тогда как когерентность отдельного
   кубита затухает лишь асимптотически.

### Два сценария

| Метка | Гамильтониан |
|---|---|
| **D** | XXZ: `J(σx σx + σy σy + σz σz)` |
| **E** | TFIM: `J σz σz + h(σx⊗I + I⊗σx)` |

### Adaptive prior — попытка починить физику

Раз OLS-предпосылка ломается, вводим **гейт**: если качество самого OLS-фита
плохое (`R²_OLS < τ`), физическую оценку **выбрасываем** и позволяем сети
предсказывать напрямую:

```
T_физика = −1/наклон − t_obs,  если R²_OLS ≥ τ и наклон < 0
T_физика = 0,                  иначе
```

Гейт применяется одинаково при обучении и при инференсе — модель учится на том
же сигнале, который получит в бою.

### Эксперимент E6a — ablation на двух кубитах

| Вариант | D: R² | D: MAE | D: AUROC | E: R² | E: MAE | E: AUROC |
|---|---|---|---|---|---|---|
| `physics_only` | −0.687 | 1.303 | 0.843 | −4.267 | 2.706 | 0.727 |
| `lstm_only` | 0.673 | 0.802 | 0.847 | 0.377 | 1.077 | 0.743 |
| `physics_lstm` | 0.636 | 0.897 | 0.819 | 0.455 | 1.049 | 0.789 |
| `transformer` | **0.897** | **0.444** | **0.929** | **0.689** | **0.718** | **0.840** |

**Здесь главный — и неудобный — результат работы.**

На одном кубите остаточная архитектура уверенно выигрывала. **На двух кубитах
она проигрывает:** на XXZ `physics_lstm` (0.636) хуже даже чистой сети
`lstm_only` (0.673), и обе далеко позади трансформера (0.897).

**Почему.** Физический prior здесь — не полезная подсказка, а **структурно
неверное** начальное приближение. И поскольку в нашей архитектуре физика
входит жёстко (в этом было её преимущество на одном кубите!), сеть не может
просто её проигнорировать — она вынуждена компенсировать ошибку через δT.
Трансформеру же нечего преодолевать: у него нет неверной отправной точки.

> В статье это зафиксировано честно, как **опровержение** переноса claim'а
> из первой работы, а не замаскировано. Рекомендация для двух кубитов —
> **чистый Transformer**.

#### Как читать строку `physics_only` (важная оговорка)

Значения R² = −0.687 и −4.267 надо читать как **«формула здесь неприменима»**,
а не как калиброванную меру «насколько плоха». Причина:

`T₂ = −1/наклон` — это **гипербола**: она взрывается, когда наклон стремится к
нулю снизу. А в реализации есть ветка: если наклон ≥ 0, вернуть потолок `t_max`.
У двухкубитных систем когерентность осциллирует и выходит на плато, поэтому
околонулевые наклоны встречаются часто, и каждое такое окно даёт ошибку
порядка `t_max`. R² — квадратичная метрика, поэтому горстка таких окон съедает
всё значение.

Диагностика показала: снятие только насыщенных окон поднимает R² на TFIM
с −15.9 до −2.25, а изменение потолка двигает R² на порядок, не трогая
медианную ошибку. Поэтому в таблицу добавлен **MAE** — по нему видно
пропорциональную картину: `physics_only` хуже трансформера примерно в **3×**
(D) и **3.8×** (E), а не «бесконечно».

Строку при этом **оставили** — на ней держится центральный аргумент статьи,
и убирать baseline потому, что он плохо выглядит, было бы выборочной
отчётностью.

### Эксперимент E6b — шум

| σ | R² | MAE | AUROC |
|---|---|---|---|
| 0.000 | 0.537 | 0.620 | 0.813 |
| 0.050 | 0.544 | 0.616 | 0.826 |
| 0.100 | 0.544 | 0.616 | 0.825 |

Устойчивость **исключительная**: во всём диапазоне R² укладывается в разброс
0.007, AUROC — в 0.013. AUROC даже слегка **растёт** с шумом (небольшой шум
работает как регуляризация).

Честная оговорка: по **стабильности** это лучше однокубитного случая
(там ΔR² = 0.23), но по **абсолютному уровню** AUROC ≈ 0.82 — ниже планки
0.90, которую первая работа брала.

### Эксперименты E7a / E8c / E11a — обобщение между системами

Одна модель обучается на смеси D+E и проверяется на каждом по отдельности.
Лучшая конфигурация (**E11a**, Transformer, окно 20, min-gap 10):

| Сценарий | R² | MAE | AUROC |
|---|---|---|---|
| D (XXZ) | **0.817** | 0.616 | **0.937** |
| E (TFIM) | 0.566 | 0.900 | 0.888 |

Прогресс относительно стартового пилота на 100 траекториях внушительный:
XXZ R²: 0.523 → 0.817; TFIM R²: −0.381 → 0.566.

Но **цель 0.70 по TFIM не взята**. И вот объяснение почему — самая интересная
часть работы.

### Эксперимент E7c — провал предсказуемости у фазового перехода

Обучаем отдельную модель для каждого фиксированного значения связи `J`
(поперечное поле `h = 1.0` зафиксировано, квантовый фазовый переход при `J = h`):

| J | R² | MAE | AUROC | Фаза |
|---|---|---|---|---|
| 0.2 | **0.876** | 0.470 | **0.959** | глубоко парамагнитная |
| 0.5 | 0.770 | 0.612 | 0.863 | парамагнитная |
| 0.8 | 0.469 | 1.270 | 0.784 | подход к переходу |
| 1.0 | 0.497 | 1.231 | 0.763 | **точка перехода** |
| 1.2 | **0.319** | **2.780** | **0.555** | ← **худшая точка** |
| 1.5 | 0.836 | 0.757 | 0.942 | ферромагнитная |
| 2.0 | 0.614 | 1.315 | 0.770 | глубоко ферромагнитная |

**Предсказуемость декогеренции проваливается вблизи квантового фазового
перехода** и восстанавливается вдали от него с обеих сторон. При J = 1.2 AUROC
падает до 0.555 — это почти подбрасывание монетки.

#### Почему так — теоретическое объяснение

Здесь важна честность: у нас **N = 2**, а настоящий фазовый переход существует
только в термодинамическом пределе (N → ∞). В конечной системе не бывает
истинной неаналитичности — только сглаженный кроссовер. Поэтому объяснение
строится не на «переходе» как таковом, а на точном спектре.

Гамильтониан N = 2 TFIM блок-диагонализуется по чётности `P = σx ⊗ σx`
(она коммутирует с H) на два точно решаемых сектора 2×2:

```
E(P=+1) = ±√(J² + 4h²)
E(P=−1) = ±J
```

Обе ветви **гладкие** по J — что прямо подтверждает: конечный размер смывает
неаналитичность. Но качественно меняется **отношение расщеплений** секторов:

```
r(J) = J / √(J² + 4h²)
```

Оно монотонно растёт от `r → 0` (глубоко парамагнитная фаза: доминирует один
сектор, динамика фактически одночастотная) до `r → 1` (глубоко ферромагнитная:
оба масштаба снова идут вместе).

Ключевое: **диссипатор амплитудного затухания не коммутирует с P**
(`σx σ₋ σx = σ₊`), то есть диссипация активно **перемешивает сектора**.
Это перемешивание наименее вредно там, где один сектор доминирует над другим
(`r ≈ 0` или `r → 1` — глубоко в любой из фаз), и наиболее вредно в полосе
`J ∈ [0.8, 1.5]`, где `r(J) ∈ [0.37, 0.60]` и ни одна частота не доминирует.
Тогда `C(t)` имеет **два сопоставимых по весу и скорости канала** вместо
одного — а по короткому раннему окну экстраполировать сумму двух близких мод
принципиально труднее, чем одну.

Это объясняет и **асимметрию** провала: `r(J)` растёт монотонно, а не имеет
симметричный пик в `J = h`, поэтому худшая точка — `J = 1.2`, а не ровно 1.0.

> Вывод: потолок R² на TFIM — **структурное свойство модели**, а не недостаток
> обучения. Больше эпох или данных его не уберут.

Практическое следствие: железо, работающее вблизи TFIM-подобного фазового
перехода (например, некоторые схемы потоковых кубитов), будет иметь наименее
надёжное раннее предупреждение — это стоит закладывать в политику планирования
коррекции ошибок.

### Итог статьи 2

1. **Adaptive prior** снимает катастрофу чистой формулы на TFIM
   (с R² = −4.27 у `physics_only` до +0.455 у `physics_lstm`).
2. **Масштабирование данных работает**: TFIM cross-system с −0.381 до +0.575.
3. **Для двух кубитов рекомендуется Transformer** — остаточная архитектура
   здесь проигрывает. Перенос главного вывода первой статьи **опровергнут**.
4. **Оптимальный порог τ зависит от гамильтониана**: 0.5 для XXZ, 0 для TFIM
   (по регрессии; по AUROC — наоборот, что делает выбор компромиссом).
5. **Провал предсказуемости у фазового перехода** с точным конечноразмерным
   объяснением — самостоятельный результат.
6. Исключительная устойчивость к шуму по стабильности (разброс R² = 0.007).

## 4. Как две работы соотносятся

| | Статья 1 (1 кубит) | Статья 2 (2 кубита) |
|---|---|---|
| Физический prior | **Необходим** (без него провал) | **Вреден** (структурно неверен) |
| Лучшая архитектура | `physics_lstm` | `transformer` |
| Аналитический предел | Есть и работает (A: 0.999) | Неприменим |
| Раннее предупреждение | AUROC ≥ 0.93 с f = 0.05 | AUROC 0.937 (XXZ) / 0.888 (TFIM) |
| Потолок | Нет принципиального | Есть, у фазового перехода — объяснён |

**Главная сквозная мысль:** встроенный физический prior — не универсальное
добро. Он даёт огромный выигрыш ровно там, где физическая модель верна, и
становится обузой там, где она структурно неверна — причём именно потому, что
встроен жёстко. Это не провал подхода, а **точное очерчивание границ его
применимости**, что честнее и полезнее, чем универсальное «наш метод лучше».
