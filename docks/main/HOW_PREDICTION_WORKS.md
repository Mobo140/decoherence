# Как мы предсказываем декогеренцию

Пособие для рассказа. Формулы сверены с `LSTMPredictor.predict` и `QuTipSimulator`, не с шапкой README.

## Одна фраза

По короткому начальному окну наблюдаемых — **без знания γ(t)** — выдаём оставшееся время до T₂ и вероятность, что декогеренция случится в горизонт Δt (обычно 1).

Не восстанавливаем γ(t). Это inverse-задача (arXiv:2505.06928); на коротком окне она ломается (E5: inverse R² ≈ −0.86 при f=0.10, direct 0.92).

## Что на входе и выходе

Вход: окно W шагов (Pauli + L1-когерентность + purity), абсолютное время конца окна t_obs.

Выход:

- `t_decoh_predicted` = t_obs + remaining
- `risk_score` ∈ [0, 1] ≈ P(remaining ≤ Δt)
- если risk ≥ 0.7 → событие `RiskThresholdExceeded`

## Цепочка

1. **Симуляция.** Lindblad. T₂ — первое пересечение L1 с (1/e)·C(0), линейная интерполяция. Не пересекли до t_max → censored, T₂ = t_max как нижняя граница.
2. **Окно.** Только окна с концом строго до T₂, чтобы remaining > 0. Риск-метка: 1 если remaining ≤ Δt.
3. **Physics prior.** OLS по log C. Const γ + σ₋: формула точная. Осцилляции (TFIM): склон по огибающей. OLS R² < τ (обычно 0.7) → prior = 0.
4. **Две головы.** BiLSTM + скаляры prior. Регрессия учит δT. `remaining = max(0, phys + δT)`. На обучении риск-голова auxiliary. В `predict()`: `risk = σ(−5 · (remaining − Δt))`.

## Формула prior

C(t) = C₀ exp(−γ t / 2) ⇒ slope = −γ/2 ⇒ T₂ = −1/slope.

Склон по локальному времени окна (0, dt, …); slope тот же, что по абсолютному t.

```
remaining_phys = clip(−1/slope − t_obs, 0, t_max)
```

slope ≥ 0 или сработал τ → phys = 0, работу берёт LSTM.

## Скаляры сейчас (не Paper 1)

Не 4 штуки и не dim 132. Default `n_physics=7` (128+7=135), опционально J:

- t_obs, slope, log C(t_obs), phys_rem, OLS R²
- interaction_code: 0=1q σ−, 1=1q σz, 2=XXZ, 3=TFIM
- dissipator_code: 0=σ−, 1=σz
- J только если `use_J_scalar=True` (E14)

Paper 1 / E1 считались на 4 скалярах. Не смешивать «архитектура в репо» и «таблицы статьи 1».

## Когда что говорить

- A: physics_only, ML не нужен (R²=0.9995).
- B/C: residual чинит неизвестное γ(t) (B: 0.945 vs physics 0.753).
- D: Transformer w=20, R²=0.817 (E11a).
- E: лучший валидный cross-system physics_lstm 0.575 (E8c). Цель 0.70 на смеси J не взята — провал у QPT (E7c J=1.2, R²=0.319).

Раннее предупреждение: AUROC 0.933 при f=0.05. R² на коротком окне плато ≈0.73 — не обещать 0.95.

Слайдер Δt в UI двигает риск у любой модели: `risk = σ(−5 · (remaining − Δt))`. Remaining (и T₂) не меняются.

## Не повторять в докладе

- Не говорить, что слайдер работает только у physics_only.
- Не сравнивать live AUROC с таблицами статей: там риск шёл из головы сети, теперь из remaining+Δt.
- Комментарий в коде «code 0=XXZ, 1=TFIM» врёт. Смотри 4-класс выше. Баг E9 был именно в этом.
- Hilbert-огибающая чуть поднимает physics_only на XXZ, LSTM не заменяет.
